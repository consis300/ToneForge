# ToneForge

Phone-first web app for building custom guitar & bass pedalboards and tones — by Collin Featherstone.

- **Play** a virtual guitar or bass (chord pads + strum strings, or a full fretboard) — no instrument needed
- **Build pedals**: 16 circuits plus the Forge Drive custom pedal (pick a clipping shape, EQ, blend); rename, recolor, reorder, save to My Pedals
- **Amps**: 4 guitar amps, 3 bass amps, and Direct Out for running your phone into a real amp
- **Tones**: factory presets, save your own, share tone codes
- **Live input**: plug in through an audio interface (works when opened from GitHub Pages)

Open: https://consis300.github.io/ToneForge/
